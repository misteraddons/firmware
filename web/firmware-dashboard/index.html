05 / UPDATE

Explicit approval

Browser flashing is unavailable. Manual BOOTSEL copying cannot prove that RPI-RP2 is the device identified in application mode.

Manual fallback — not identity-verified

  1. Use only the validated file this dashboard downloaded for the product you selected. Images for sibling products share the RP2040 family and will copy without complaint.
  2. Disconnect other RP2040 bootloader devices.
  3. Enter BOOTSEL on the intended device and manually copy the validated UF2 to RPI-RP2.
  4. Reconnect through serial and verify PRODUCT, UID, firmware version, and health.

The dashboard does not claim that manual copying preserves device association.
